# Stadtservice Wien V4

V4 ist stärker als echte Schalterarbeit aufgebaut.

- verschiedene Arbeitsformulare je Kundenanliegen
- du musst Daten selbst eintragen oder korrigieren
- interne Notizen schreiben
- Entscheidungen treffen
- Zwischenspeichern
- Vorgang erst nach einer Entscheidung abschließbar
- Meldeänderung, Parkberechtigung, Fundservice, Dokumentenausgabe,
  Meldebestätigung, Terminproblem, Vollmacht und Beratung haben eigene Abläufe
- Dokumentvorschau, Beratungsantwort und Bearbeitungsergebnis auf Bildschirm 2
- moderneres UI
- viele fiktive Bürger-, Termin-, Fund- und Vorgangsdaten
